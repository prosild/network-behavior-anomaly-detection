# DD-008. 합성 APT 패턴 주입으로 ML·DL 모델 시험

- 결정일: 2026-11-06
- 요청·결정: 사용자(DD-006 수정 절 우선순위 3, 2026-11-06 일정 승인). 패턴·파라미터·평가 규칙은 Claude가 정했다.
- 관련: [DD-006](DD-006-behavior-detectors-reduced.md) 수정 절, [DD-007](DD-007-tgn-event-graph.md), [DD-005](DD-005-deadline-scope.md) 일정 수정 절
- 설정: [configs/synthetic/apt-injection.v1.json](../../configs/synthetic/apt-injection.v1.json). 모델 점수를 보기 전에 고정했다.

## 왜 하나

- CIC-IDS2017의 공격은 대부분 시끄러운 스크립트 공격이다. APT처럼 조용하고 오래가는 행동은 Botnet과 Infiltration 정도다.
- 그래서 "ML·DL 모델이 APT 같은 행동 이상에 대응하는가"를 CIC 결과만으로는 말하기 어렵다.
- 정답을 정확히 아는 행동을 실제 배경 트래픽에 섞어 모델을 시험한다. 정답은 주입한 연결의 uid라서 라벨 오류가 없다.

## 어떻게 주입하나

- **위치:** 화~금 Zeek 로그(run-02)의 사본에 넣는다. 합성 캡처는 `syn1-tue`~`syn1-fri`다. 원본 로그와 기존 결과는 그대로다.
- **형식:** conn 행과, 그 uid에 딸린 프로토콜 로그 행(dns, ssl, kerberos, smb_mapping, smb_files, dce_rpc)을 함께 만든다.
  - 필드 이름·순서·`community_id`는 Zeek 출력과 같다. `community_id`는 실제 행으로 계산이 맞는지 시험했다.
  - 크기·history·상태·기록 지연(`_write_ts`)은 월요일 실제 로그를 본떴다.
  - 주입 행은 `_write_ts` 순서로 원래 행 사이에 끼워 넣는다. 원래 행은 순서와 내용이 그대로다.
- **월요일은 바꾸지 않는다.** 그래서 월요일 train으로 적합한 어휘·표준화·모델이 그대로 쓰인다. 모델을 다시 학습하지 않는다.

## 패턴 5개 (하루에 하나씩, 공격 호스트는 서로 다르다)

| 패턴 | 행동 | 회피 성격 |
| --- | --- | --- |
| `beacon_https` | 새 외부 IP:443에 약 5분 간격(±20%) 작은 TLS 연결, 2시간. 30분마다 C2 도메인 DNS 조회 | 흔한 포트·TLS, 작은 크기 |
| `slow_exfil` | 새 외부 IP:443에 약 10분 간격 3~8 MB 업로드, 2시간 | 한 창에는 연결 하나뿐 |
| `dns_tunnel` | 내부 DNS 서버에 긴 무작위 하위 도메인 A 질의, 5~15초 간격 30분 | 흔한 A 질의, 내부 리졸버 경유 |
| `lateral_smb` | 대상 4개에 Kerberos TGS → SMB ADMIN$ 매핑·실행 파일 쓰기 → DCE-RPC svcctl 서비스 생성·시작(psexec 방식), 10~20분 간격 | 정상 SMB·Kerberos와 같은 포트 |
| `internal_scan` | 대상 6개 × 포트 6개를 섞어 60~140초 간격 connect scan | 느린 속도 |

- 외부 IP는 월요일 train 외부 IP가 많이 쓰는 /16 대역(클라우드 등) 안에서, 다섯 날 어디에도 없는 주소로 만든다. 낯선 대역만으로 티가 나지 않게 하기 위해서다.
- 시각은 무작위(seed 고정)다. 캡처 양끝에서 30분 떨어뜨린다. 같은 (자산, 역할)의 CIC 정답 창이나 다른 합성 정답 창과 30분 안에 있으면 다시 뽑는다.

## 정답

- 주입 conn의 창(`floor(_write_ts/300)*300`)에서 공격 호스트의 originator 창, 그리고 측면 이동·정찰 대상의 responder 창이다.
- DNS·Kerberos 서버(192.168.10.3)의 responder 창은 넣지 않는다. 모두가 쓰는 기반 서버라 다른 사건과 우연히 겹친다.
- 20건 모두 confirmed다.

## 평가

- 모델은 다시 학습하지 않는다. 합성 캡처를 기존 파이프라인(Silver → Gold, 이벤트 표 → 그래프)으로 다시 만들고 점수만 다시 매긴다.
- 임계값은 기존과 같은 월요일 보류 p95다.
- **주 지표:** 합성 에피소드 20건이 분모인 Recall@N. 조사 큐에서 CIC confirmed 에피소드와 겹치는 사건은 뺀다(이미 처리된 공격으로 본다).
- **보조 지표:** CIC 사건을 빼지 않은 큐의 Recall@N.
- 패턴별 결과(5패턴 × 4일)를 같이 보고한다.

## 한계

- 패턴과 크기는 Claude가 정했다. 실제 APT 도구의 트래픽이 아니라 Zeek 로그 수준의 모사다. 패킷을 만들지 않았으므로 Zeek가 실제로 이렇게 기록하는지는 확인하지 않았다.
- 정답 규칙을 아는 사람이 만든 패턴이라, 특정 모델에 유리하게 고르지 않도록 모델 점수를 보기 전에 설정을 고정했다.
